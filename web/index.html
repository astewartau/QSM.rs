QSM.rs

The Rust engine for Quantitative Susceptibility Mapping. A from-scratch library implementing 50+ published algorithms across the full reconstruction chain — the same engine that powers QSMxT and QSMbly.

API documentation → View on GitHub

Get started

Add the crate as a git dependency, then reconstruct in a few lines. There's a high-level pipeline API and a low-level building-block API — both shipped as runnable examples.

Cargo.toml
# A single git dependency — no system libraries
[dependencies]
qsm-core = { git = "https://github.com/astewartau/QSM.rs" }

# optional: multi-threading and SIMD
# features = ["parallel", "simd"]
high-level pipeline
let field = run_field_mapping(&phases, Some(&mags),
    &mask, &meta, &cfg, &mut cb)?;
let bg = run_bg_removal(&field.b0_field_ppm,
    &mask, &meta, &cfg, &mut cb)?;
let chi = run_dipole_inversion(&bg.local_field_ppm,
    &bg.eroded_mask, &meta, &cfg, mag, &mut cb)?;

50+ algorithms, every stage

A complete reconstruction toolkit. Classical methods are validated against a reference implementation in Julia, MATLAB, or C++; the 16 deep-learning methods (marked DL) run through ONNX and need the onnx feature plus downloadable weights. See the README for the full citation list.
